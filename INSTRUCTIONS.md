## Where i Start?

you first need to run the DNes.lua or DTDBTL.lua (BootLoader) and it will automatically run the BootStrap session, now, you need to install the plugin package typing only "loadpack" in the bootstrap command (YOU NEED THE DTDPX.dtdp.lua TO USE really... so... type loadpack before start) and when installed you type start to start the whole system, PLEASE CONFIRM THE DTDPX.dtdp.lua PLUGIN IS ON THE SAME DIRECTORY OF DTDBTL.lua OR IT WILL NOT WORK.

## How to use?

just type help to see the list of commands in the input! the shell as been created for hobby and community expansion and the users have the objective of create an variety of servers packs and stuff to stock on the shell, the shell can be expanded by using plug-ins to create new commands and things for the shell, and the MAIN COMMAND **connect** to acess servers thats works actually as remote code (you acess to load a valid lua code) you acess **servers** to add servers or view servers to connect, AND THE MAIN SERVER **market**, here you share your packs and you can download and install others users packs of any type so long as it is text or something (it use valid string values to work) and you can use for everything that you want!
type **connect <server>** to connect to a server

## Who is the commands?

type **help** for more info or read this:
*pi*: or **plugin** [init (plugin name or void for all), ls] *manage plugins session*

*connect*: [connect (your url or server hostname)] *connect to a url and load valid lua code and execute*

*out*: [out "(your text here)"] *LITERALLY PRINT EVERYTHING BETWEEN THE QUOTES!*

[click here](https://raw.githubusercontent.com/DTD/main/DTDPX.dtdp.lua) to see an example of plugin structure and to see the code to view with more precision the commands

## Default Servers for you!
(tip! the servers are not a command so, type **connect** first)

### market

use **connect market** cmd to acess the market. To install a pack you need to type a pack name or something and if it show the current pack that you want Just type ENTER to install in your device. if you want to search, Just type search (your query) to find some packs. type exit to exit.

### servers

show the servers working in DTD, type exit to exit,  type create to open creating hub.

### marketstudio

Just an server for you deploy your files, type help for more info.

### accounts
